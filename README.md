# Licious Operations Management Dashboard

## Upload this folder to GitHub
Keep `index.html` in the repository root.

### GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Branch: **main**
4. Folder: **/(root)**
5. Click **Save**.

The dashboard uses the supplied analytical outputs and figures from the MBA project. It uses synthetic data because proprietary Licious operational data are unavailable.

The chart library is loaded in the browser from Chart.js's public CDN.
